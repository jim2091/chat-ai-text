# 개발 변경 이력

개발 지시에 따른 변경 및 추가 사항을 시간 순서대로 기록합니다. 이후 항목은 다음 번호로 이어서 추가합니다.

## 001 - AI Playground 채팅 SPA 구현

- `src/App.jsx`: 교수님, 할아버지, 어린이, 사용자 지정 AI 모드와 각 API 요청·응답 처리를 구현했습니다.
- `src/App.css`: 채팅 버블, 로딩·오류 상태, 반응형 레이아웃을 구현했습니다.

## 002 - 런타임 오류 및 전역 CSS 정리

- `src/App.jsx`: 선택된 모드 조회에 fallback을 추가하고 입력 가능 여부를 명확한 boolean으로 처리했습니다.
- `src/index.css`: Vite 기본 스타일을 최소 전역 reset으로 정리했습니다.
- `src/App.css`: 긴 응답 문자열의 화면 넘침을 방지했습니다.
- `getDataStatus` 및 환경 전용 전역 API 호출은 현재 소스에서 발견되지 않았습니다.

## 003 - 모드별 대화 내역 유지

- `src/App.jsx`: 일반 AI 모드별 대화를 `messagesByMode` state에 분리해 저장하도록 변경했습니다.
- 모드 전환 시 대화 내역을 초기화하지 않도록 수정했습니다.

## 004 - 변경 이력 기록 체계 추가

- `docs/CHANGELOG.md`에 이후 개발 지시별 변경 내역을 번호순으로 계속 기록합니다.
